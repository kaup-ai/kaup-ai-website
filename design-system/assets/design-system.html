§ 00 · Brand & Logo

设计系统从一个 mark 开始

5 个 SVG 变体 × 2 套配色(亮/暗)= 10 个生产文件。所有颜色、间距、字号都从这里开始。Mark 的路径数据来自 brand-spec.md §4.1 · Kaup Curve v5.2(curve chevron + 琥珀点)。

Mark anatomy · Kaup Chevron v5.2

2 元素 · 极简单一图形(像 Apple / Nike / Twitter 的路子):

  1. Chevron ">" — 粗体 cubic-Bezier 曲线,峡湾深蓝 var(--brand),整体绕 (50,50) 旋转 -15°(SVG 负值 = 逆时针 = 向上)。语义:上升前进 / 增长 / AI 进步。
  2. 琥珀点 — 嵌在 chevron 偏左下 (cx=76, cy=50)(原 cx=80, cy=50 → v1.5.0 中间值 cx=73, cy=52 → v1.5.1 最终 cx=76, cy=50),fill="#E89B3C"(var(--accent)),永不改色。尺寸: r=5(chevron stroke 50%)。位置契约:r=5 撑大后 dot 会盖住尖端段 (80,50)→(85,50),旋转 -15° 后看起来"贴片压刀锋"。(76, 50) 距 V 字顶点 (85, 50) 旋转后约 9 单位,距 chevron spine (80, 50) 旋转后约 4 单位——dot 嵌在 chevron body 内 1 单位位置(cradle 在 V 字切口的内壁),V 字顶点 cusp 与 chevron spine 两条边都清晰,"披荆斩棘"锐利之气 + V 字切口里居中 双约束同时满足。AI 信号在方向心脏。**10 个 SVG 源 + 内嵌 symbol 全部用 (76, 50)**——保持同步。

⚠️ 不要给 chevron 装冰川白方块(早期版本有,header 里看着像"贴了个 badge",已移除)。不要给琥珀点加描边/动画/光晕/任何 overlay 元素 — 琥珀点是单点品牌承诺,halo 会改变视觉身份。琥珀点尺寸固定 r=5(改 r=3.5 / r=2 都验证过,40-72px app header / brand card 不可见)。Mark 在 <symbol id="kaup-chevron"> 复用,改一处全站更新。

同步规则

  1. 改 token 值 → 先改 tokens.css(canonical),再改本页 CSS(同步镜像),再改 DESIGN.md YAML 注释里引用 token 的字段。
  2. 改 component API → 先改 DESIGN.md YAML 的 components.*(spec),再改本页 CSS + showcase(实现)。
  3. 加新 token → tokens.css 9 组中选一个最相关的组,加 token + 注释 + dark theme override(若需),然后在 DESIGN.md §2 colors/spacing/rounded 加 YAML 字段(若 schema 涵盖)。
  4. 加新 component → 在 DESIGN.md §2 components 加 YAML 块(给出 backgroundColor / textColor / rounded / padding / typography),然后在本页加 CSS + showcase。
  5. 改 logo → 改 brand-spec.md §4(canonical 描述) → 改 5 个 SVG 源文件 → 本页 <defs> 里的 <symbol> path 同步更新(改一处全站更新) → scripts/export-png.sh 跑一遍重生成 PNG。
§ 06 · Metal

金属质感：色相锁定，只动明度

两层体系：拉丝纹理层（feTurbulence 各向异性 + 4px 机加工细丝线）只用于 hero/CTA 两处金属表面；整页机加工语言（凸起板材 / 铣削凹槽 / 机加工按键帽 / 拉丝芯片 / 金属墨渐变）用亮度曲线 + 内高光 + 分层投影做材质暗示。一个顶光源推导全页明暗：页面=台面，卡片=凸起板，输入框=凹槽，按钮=按键帽。所有色值锁定 fjord 蓝家族（--fg/--brand 同族），验证：9 组最不利停靠点对比度 ≥8.19:1。

配额与硬约束

  • 拉丝纹理仅 hero + CTA 两处金属表面/屏（与琥珀 ≤2/屏 同一底层逻辑）
  • 亮色背景承载纹理约为暗色的 1/3 —— 亮色 alpha 需加强（grain 0.16 / lines 0.034）
  • 倒角四边分色方案已废弃：亮色底上白色亮边不可见，只剩右下暗线读作「脏边」
