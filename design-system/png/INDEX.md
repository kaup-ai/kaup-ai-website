# PNG Suite

Generated by `scripts/export-png.sh` from the 10 production SVGs.

| Folder | Asset | Alignment | ViewBox | Files | Use |
|---|---|---|---|---|---|
| `app-icon/` | App icon | — | 1024×1024 | 18 sizes × 2 variants = 36 | iOS / Android / PWA / OS app |
| `favicon/` | Favicon | — | 100×100 | 3 sizes × 2 variants = 6 | Browser tab / bookmark |
| `logo-primary/` | Vertical lockup | center | 480×540 | 4 widths × 2 variants = 8 | Marketing / print / hero |
| `logo-horizontal/` | Horizontal lockup | **left** | 480×160 | 4 widths × 2 variants = 8 | App header / nav bar (default) |
| `logo-horizontal-centered/` | Horizontal lockup | **center** | 480×160 | 4 widths × 2 variants = 8 | Hero / email signature / card |

**Total: 66 PNG files** covering every common raster use case.

## Which horizontal lockup to use

- `logo-horizontal*.{svg,png}` (left-aligned) — **default for app headers, nav bars, and any layout where the logo anchors a left nav edge** (Apple / Stripe / Vercel / Linear convention). Mark hugs the left edge, wordmark starts ~21px to the right of the chevron tip.
- `logo-horizontal-centered*.{svg,png}` (center-aligned) — **for hero sections, email signatures, marketing cards, and centered compositions** where the lockup is the focal element. Mark + wordmark form a single centered block on the viewBox.

## File naming

- Square assets: `<name>-<size>.png` (e.g. `app-icon-1024.png` = 1024×1024 px)
- Width-bound assets: `<name>-<width>w.png` (e.g. `logo-primary-512w.png` = 512×576 px, `logo-horizontal-512w.png` = 512×170 px)
- `-dark` suffix = glacier-white foreground, designed for dark backgrounds (note: filename is slightly counterintuitive — both variants are present in `brand-spec.md` §4.1)

## Regeneration

```bash
./scripts/export-png.sh
```

Re-running the script wipes `png/` and regenerates from current SVG sources. PNGs are byte-identical if SVGs haven't changed.
