## Color roles

- **冰川白 Glacier** (`#f7f9fc`) — background: page canvas — ice / glacier white
- **暗夜黑 Ink** (`#0a1a2f`) — foreground: body / headings — deep ink · dark theme bg
- **峡湾蓝 Fjord** (`#0e2a47`) — accent: primary action — fjord deep blue
- **纯白 White** (`#ffffff`) — surface: card / panel surface
- **峡湾灰 Muted** (`#5b6b7e`) — muted: meta / hint / secondary text
- **冰线灰 Border** (`#dee3eb`) — border: hairline border
- **维京琥珀 Amber** (`#e89b3c`) — accent-secondary: polaris signal — max 2 visible uses per screen

## Messaging pillars

- 智 — 以AI深度驱动行业智能决策，让AI会做更懂做
- 御 — 以编排中枢守御企业运转全链路，从人驱动流程到AI驱动流程、人驱动决策
- 无 — 以开放架构承载无限场景，不绑定模型、不锁定行业
- 疆 — 以AI之力重塑企业能力版图，5人团队足以比肩50人团队
